# WhiteAesther v1.10.4 — هماهنگی اتصال دسکتاپ با اندروید

این نسخهٔ آزمایشی، اختلاف‌های مسیر اتصال دسکتاپ با اندروید ۱.۱۵ را برطرف می‌کند. هستهٔ دسکتاپ اکنون از سورس کامل Aether 2.4.0 اندروید، همراه با BoringSSL 5.3 و سازگارکننده‌های دسکتاپ ساخته می‌شود.

- اتصال خودکار و بازیابی اتصال، روش‌های H2/H3، records، compact، fragmentation، ECH روی H2/H3، IPv6، WOM و MIM را با زمان‌بندی مشخص امتحان می‌کنند.
- تنظیمات کامل روش موفق، از جمله شکل ClientHello، ECH و خانوادهٔ IP، برای شروع اتصال واقعی حفظ می‌شود. مسیرهای موفق به تفکیک شبکه به خاطر سپرده و دوباره بررسی می‌شوند.
- اسکنر چند روش اتصال را بررسی می‌کند و ترافیک واقعی را جداگانه تأیید می‌کند. آدرسی که تأیید ترافیک نشده باشد، حتی با تمام‌شدن زمان اسکن، به عنوان نتیجه برگردانده نمی‌شود.
- تنظیمات تکمیلی TLS، MASQUE SNI، API Host/SNI و گزینه‌های شکل‌دهی ClientHello به تنظیمات پیشرفته اضافه شده‌اند.
- بازیابی اتصال پس از توقف Tor یا Psiphon و ترتیب روش‌های جایگزین Tor اصلاح شده است. لغو جست‌وجو یا تغییر شبکه نیز نتیجهٔ قدیمی را از شروع یک اتصال تازه بازمی‌دارد.
- ثبت‌نام و فعال‌سازی identity، بکاپ‌های قبلی، نگهداری پورت‌ها و تنظیمات صریح کاربر حفظ شده‌اند. هسته‌های ناسازگار با قابلیت‌های این نسخه پیش از اجرا شناسایی می‌شوند.

پروفایل‌ها و identityهای قبلی قابل استفاده‌اند. اگر Core executable را دستی تنظیم کرده‌اید، برای استفاده از هستهٔ همراه این نسخه آن را خالی کنید. در ویندوز، پوشش کل سیستم با **Full tunnel** و دسترسی Administrator فعال می‌شود؛ System proxy تنها برنامه‌هایی را پوشش می‌دهد که تنظیمات پراکسی را رعایت می‌کنند.

اعتبارسنجی محلی ویندوز شامل ۵۲۳ تست هسته، ۲۲۸ تست بک‌اند، ۷۲ تست فرانت‌اند و ۱۵ تست مرورگر بوده است. هر دو نصب‌کنندهٔ EXE/MSI نیز استخراج و هستهٔ داخل آن‌ها بررسی شده است. موفقیت تست‌ها تضمین اتصال روی تمام شبکه‌ها نیست؛ تست میدانی روی شبکهٔ کاربران هنوز لازم است.

جزئیات فنی و محدودیت‌های بررسی: [جدول تطبیق اندروید و دسکتاپ](https://github.com/WhiteDNS/WhiteAesther/blob/v1.10.4/docs/ANDROID-DESKTOP-PARITY.md).
