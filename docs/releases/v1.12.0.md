# WhiteAesther v1.12.0 — هم‌گام با اندروید 1.16

- **هستهٔ Aether از نسخهٔ اندروید 1.16.0.** راه‌اندازی API کلادفلر اکنون یک مسیر out-of-band هم دارد که سه ثانیه بعد از بقیهٔ مسیرها شروع می‌شود و مثل همهٔ آن‌ها گواهی را تأیید می‌کند. روی شبکه‌ای که مسیر عادی جواب می‌دهد چیزی عوض نمی‌شود.
- **رمز روی شنوندهٔ محلی ورکر.** شنوندهٔ SOCKS که Xray برای Cloudflare Worker روی همین دستگاه باز می‌کند، در هر نشست نام کاربری و رمز تصادفی تازه دارد. برنامه‌های دیگرِ روی دستگاه دیگر نمی‌توانند از آن استفاده کنند. خود برنامه، mihomo و اشتراک در شبکه مثل قبل کار می‌کنند و لازم نیست چیزی تنظیم کنید.
- **فقط IPv4 یا فقط IPv6.** گزینهٔ **Addresses** تعیین می‌کند موتور به کدام نشانی‌های Cloudflare وصل شود؛ برنامه‌های داخل تونل همچنان هر دو را دارند. با «فقط IPv6»، اگر شبکه نشانی IPv6 نداشته باشد هشدار نمایش داده می‌شود. نقطهٔ پایانی سفارشی‌ای که با گزینه نخواند پیش از اتصال رد می‌شود. تغییر گزینه حین اتصال، اتصال را دوباره برقرار می‌کند.
- **وارد کردن فهرست قوانین مسیریابی.** در **Traffic ← Routing rules** فهرست «هرگز نفرست» یا «بدون تونل» را از یک فایل محلی وارد کنید: دامنه، فایل hosts، IP و CIDR، یا فهرست قوانین Clash. گزارش ورود می‌گوید چه چیزی و چرا کنار گذاشته شد. هر فهرست را جدا روشن، خاموش یا حذف کنید. جعبهٔ «این مقصد با کدام قانون می‌خورد؟» بدون جست‌وجوی DNS جواب می‌دهد. قوانین اکنون زیر همهٔ حامل‌ها اعمال می‌شوند: Aether، Psiphon، Tor و Worker.
- **تنظیم‌هایی که اتصال فعلی از آن‌ها استفاده نمی‌کند** با یک توضیح کوتاه مشخص شده‌اند. اگر Aether در یکی از دو مرحلهٔ زنجیره باشد، تنظیم‌هایش نمایش داده می‌شوند.
- در فرم ورکر، رفتن به حالت Fragment یا Browser گزینهٔ ECH را خاموش می‌کند.
- متن گزینهٔ «بدون مبهم‌سازی» روشن می‌گوید روی شبکهٔ فیلترشده بیشترین احتمال را دارد که اتصال را از کار بیندازد.
- جست‌وجوی خودکار، H3 را فقط وقتی اول امتحان می‌کند که آخرین بار روی همین شبکه با H3 وصل شده باشید؛ در غیر این صورت H2 اول است.
