# WhiteAesther v1.11.0 — ورکر کلادفلر

روش اتصال تازهٔ **ورکر کلادفلر**، هم‌راستا با نسخهٔ ۱.۱۵ اندروید، به دسکتاپ اضافه شد.

- **ساخت و مدیریت از داخل برنامه:** با توکن API کلادفلر، Worker یا Pages شخصی بسازید، به‌روزرسانی کنید یا حذف کنید. دامنهٔ سفارشی و آمار مصرف هم از همین صفحه در دسترس است. فهرست سایر Workers و Pages حساب نیز نمایش داده می‌شود و می‌توان آن‌ها را حذف کرد.
- **اتصال مستقل VLESS** در سه حالت Normal (بهترین پینگ بین آدرس‌های تمیز و پورت‌ها)، Fragment و Browser Dialer. «متصل» فقط بعد از عبور یک درخواست واقعی TLS نمایش داده می‌شود.
- **سایت‌های پشت کلادفلر** از طریق Proxy IP خودتان و در صورت نبود آن از درگاه‌های عمومی NAT64 باز می‌شوند. همهٔ درگاه‌ها به نوبت امتحان می‌شوند تا یک درگاه از کارافتاده سایت را از دسترس خارج نکند. این درگاه‌ها نشانی مقصد را می‌بینند ولی محتوای رمزشده را نه.
- توکن API ذخیره نمی‌شود و فقط تا وقتی صفحه باز است در حافظه می‌ماند. شناسهٔ اتصال در لاگ‌ها پنهان می‌شود.
- موتور ورکر (Xray) از سورس نسخهٔ پین‌شده ساخته می‌شود و برنامه نسخه و checksum آن را پیش از هر اجرا بررسی می‌کند.
- صفحهٔ وضعیت اکنون نام روش اتصال (Psiphon، Tor یا ورکر کلادفلر) را درست نشان می‌دهد و تأخیر ورکر را با مقصدی بیرون از کلادفلر اندازه می‌گیرد.

اگر Worker را با نسخهٔ آزمایشی ساخته‌اید، از صفحهٔ ورکر روی **Update deployment** بزنید تا اسکریپت جدید روی کلادفلر قرار بگیرد. پروفایل‌ها و identityهای قبلی بدون تغییر قابل استفاده‌اند.
