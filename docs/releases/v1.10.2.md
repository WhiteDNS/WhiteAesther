# WhiteAesther v1.10.2 — بهبود دریافت و فعال‌سازی identity

این انتشار آزمایشی، اصلاحات اصلی شبکه و identity از Aether 2.4.0 را به fork دسکتاپ منتقل می‌کند. پایهٔ هسته همچنان 2.3.0 است و تغییرات با پچ `restricted-networks-v2` ارائه می‌شوند.

- دریافت identity از API جدید Cloudflare با مسیر جایگزین برای دامنهٔ قبلی انجام می‌شود. مسیرهای TLS پیش از ارسال ثبت‌نام بررسی می‌شوند و درخواست با نتیجهٔ نامعلوم دوباره ارسال نمی‌شود.
- فعال‌سازی WARP برای identityهای تازه اضافه شده است. ثبت‌نام پیش از ادامهٔ عملیات ذخیره می‌شود تا قطع اتصال یا بستن برنامه باعث ثبت‌نام تکراری نشود.
- پورت‌های SOCKS و HTTP هنگام راه‌اندازی و اتصال مجدد در اختیار برنامه می‌مانند. مدیریت gatewayهای زودقطع‌شونده نیز بهبود یافته است.
- ورودی نامعتبر upstream باعث توقف می‌شود تا اتصال ناخواسته از کنار پروکسی تعیین‌شده عبور نکند.
- اعتبارسنجی گواهی API و DoH، پین‌های MASQUE، اسکنر، بکاپ identity و اصلاحات اختصاصی شبکه‌های محدود حفظ شده‌اند. پین تازهٔ MASQUE و فهرست gatewayهای upstream نیز اضافه شده‌اند.

پروفایل‌ها و بکاپ‌های قبلی قابل استفاده‌اند. identityهای قدیمی صرفاً به دلیل ارتقا دوباره ثبت یا فعال‌سازی نمی‌شوند. اگر برای Core executable مسیر دستی گذاشته‌اید، آن را خالی کنید تا هستهٔ همراه برنامه اجرا شود.

این نسخه شامل ارتقای BoringSSL به 5.3 یا تمام قابلیت‌های Aether 2.4.0 نیست. تست‌های خودکار و بررسی بسته‌ها جای تست اتصال واقعی روی اپراتور را نمی‌گیرند.

جزئیات: [اصلاحات منتقل‌شده از Aether 2.4](https://github.com/WhiteDNS/WhiteAesther/blob/v1.10.2/docs/AETHER-2.4-BACKPORTS.md).
